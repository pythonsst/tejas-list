# react-native-tejas-list

A native-first, ultra-high-performance list engine for React Native, built with Nitro Hybrid Views.

## Installation


```sh
npm install react-native-tejas-list react-native-nitro-modules

> `react-native-nitro-modules` is required as this library relies on [Nitro Modules](https://nitro.margelo.com/).
```


## Usage


```js
import { TejasListView } from "react-native-tejas-list";

// ...

<TejasListView color="tomato" />
```
